Active Directory

Školní doména (on-premise AD). Čte se přes LDAP účtem jen pro čtení (stačí běžný doménový uživatel). Je-li nastaven WireGuard, spojení na řadič domény vede přes tunel do školy.

    Edookit

    Stejné přístupy, jaké používal dosavadní synchronizační nástroj školy (proměnné EDOOKIT_* na jeho serveru). Citlivé údaje (rodné číslo apod.) aplikace nezobrazuje ani neukládá.

    Osobní údaje studentů – /api/student-data/v1/list

    API Docházka – žáci, třídy, skupiny, čísla karet

    Prázdné pole = ponechat uloženou hodnotu.
